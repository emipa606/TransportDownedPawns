![Image](https://img.litet.net/logos/Notice.png)

Allows unconscious and otherwise downed colonists and prisoners to be transported in a transport pod.

I didn't create this mod, I only updated it to work with 1.0-1.5 from the source mod which hasn't been updated in a couple of versions.

Note, the name of this mod is the same as the original but with spaces in it. Be sure you select the correct mod if you still subscribe to the old mod.

Original mod by CornyTrace:
